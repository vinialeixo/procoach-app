## Bugs conhecidos / Lacunas

1. **Diet não tem endpoint DELETE** - O soft-delete existe no domínio (`Diet.softDelete()`) mas não é exposto via REST. O teste foi removido.

2. **Endpoint `/history` retorna 404 para atleta soft-deletado** - O endpoint valida existência/posse antes de retornar histórico. O evento de deleção persiste no audit log mas não é consultável via API para atletas deletados.

3. **Check-in (MVP2) não implementado** - Teste de `CHECK_IN_REGISTERED` removido pois endpoint não existe.

4. **Versão genérica (Version entity) não valida reason** - A validação de `changeReason` obrigatório existe apenas no agregado Diet. O VersionService é genérico e não impõe essa regra.

5. **AuditLog @Version field** - O campo `@Version` do JPA é usado para optimistic locking mas o repository não expõe update, apenas append.
